# Learn About Ember Calculator

## About the Project
Ember Calculator is an Android calculator
application designed with a modern interface.

## Technology Stack
- Kotlin
- Android SDK
- Gradle
- Material Design

## Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize.
4. Build and run the application.

## Project Structure
- app/src/main/java - Application source code
- app/src/main/res - Resources and layouts
- app/src/main/AndroidManifest.xml - App configuration

## Building
Run the following command:

./gradlew assembleDebug
